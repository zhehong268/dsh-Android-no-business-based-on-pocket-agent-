# dsh Android

基于 [PocketAgent 0.2.0](https://github.com/ManojDevarajulu/PocketAgent) 改造的中文安卓手机 Agent。
可以登录 DeepSeek 账号，读取手机界面、点击和输入、联网查资料、在授权目录读写文本文件，也可以把手机接给电脑模型直接操作。

本轮版本：**0.3.0 / versionCode 3**。Android 11+，包名 `dev.pocketagent`。

安装包：[dist/dsh-phone-agent.apk](dist/dsh-phone-agent.apk)。安装与配置说明见 [dist/README.md](dist/README.md)，
本轮自检记录见 [docs/VALIDATION-2026-11-16.md](docs/VALIDATION-2026-11-16.md)。

## 这一轮重点改进

- **按模型能力分工**：手机操作使用能看图片的 DeepSeek Flash；Pro 用作按需独立复核。配置了 Pro 时，手机操作自动路由到 Flash，避免把截图发送给不支持图片的 Pro。其他服务商保留用户配置。
- **读懂控件状态**：保留勾选、选中、禁用、焦点、状态说明、资源 ID、位置和键盘状态。无法可靠上报的勾选状态明确显示 `checked=unknown`，不会假装未选中。
- **自动补图**：内容稀疏、自绘区域、执行失败、控件状态不明或操作后没有明显变化时补图；检查画面内容变化，减少纯画布被误判卡住。密码区域会遮黑。
- **按截图编号操作**：`tap_mark` 必须提供对应观察编号；重新观察后旧编号失效。节点 ID 前缀不再每 26 轮循环。
- **定位与输入更可靠**：文字匹配优先精确名称，重名返回候选；查找支持限定容器，并检测滚动失败、到底及容器变化。输入支持替换、追加、清空，并核对实际文本。
- **工具更完整**：新增重新读屏、读完整节点、查候选、等待文字或勾选状态、局部放大截图、长按、双击、拖动、保存子任务进度。
- **结果核验**：动作已发出与任务完成分开反馈。执行失败、用户拒绝、结果未确认时不能直接报成功；`done.verify_text` 可检查最终可见依据。
- **长任务和恢复**：`checkpoint` 保存当前子目标、完成摘要、下一步和验收依据；每步保存简短轨迹。首页可继续未完成任务，恢复前重新读屏，不自动重发结果不明的发送/提交。
- **操作经验**：只保存通过可见完成依据核验的成功路线，最多 12 条；进入对应应用时按需提供最多 3 条参考。历史经验作为数据处理，以当前页面为准。
- **电脑直接控制**：保留 `run_task`，增加 `control_start` 后逐步读屏和操作的模式。所有动作仍经过同一个 AgentLoop 和安全门，手机端批准后才能控制；空闲两分钟结束，手机停止或关连接也会撤销控制。
- **上下文**：Anthropic 格式保留工具与推理回放，只在请求副本省略两张以前的截图；DeepSeek Chat Completions 格式保留工具推理所需的 `reasoning_content`。
- **模型检查**：声明支持图片的模型要根据实际测试图片返回颜色和工具调用，不再只验证一次空工具调用。

## 验证结果

938 项单测：0 失败、1 跳过；APK 构建及发布分支编译通过；Lint 0 错误、111 条警告；独立模拟器 15 项设备回归通过。桌面工作区环境仍有原有安装缺失，详见验证记录。

## 使用

1. 安装 APK，设置中选择“DeepSeek 账号”登录，或自行配置模型服务商。
2. 打开无障碍服务；通知、麦克风和文件目录授权按需开启。
3. 在应用内发任务，或添加快捷设置磁贴“问 dsh”。
4. 文件工具只能访问用户通过 SAF 授权的目录，每次普通文件调用仍需确认。
5. 多步任务会使用进度记录；中断后从首页“继续任务”恢复，也可从磁贴回到当前应用后发出原任务。

电脑操作模式的流程与配置见 [docs/MCP-DIRECT.md](docs/MCP-DIRECT.md)。

## 构建和测试

源码路径需要是 ASCII；这个项目原有的 AGP 配置不接受中文工程路径。本地实际编译副本为 `C:\dshbuild\pocketagent`。

```powershell
$env:JAVA_HOME='D:\Android\JDK17'
$env:ANDROID_HOME='D:\Android\Sdk'
$env:GRADLE_USER_HOME='D:\Android\Gradle'   # 本机已有依赖缓存
$env:ANDROID_USER_HOME='D:\Android\User'   # 本机旧 APK 的 debug 签名所在目录
Set-Location C:\dshbuild\pocketagent
.\gradlew.bat :app:testDebugUnitTest --rerun-tasks
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

其他电脑按实际安装位置设置环境变量；不要复制或提交本机密钥、debug keystore、`local.properties`、账号配置和构建缓存。
本仓库保留 Gradle Wrapper，首次构建需要下载依赖。`--offline` 仅适合依赖已齐备的环境。

本机工作区还要求修改前后运行 `env-selftest.ps1`；它检查桌面 DSH 环境，结果与安卓项目测试单独记录。

## 已知限制

- 本轮提供第一遍工程改进，**不代表任意应用或长任务都已具备可靠成功率**。30 个重复任务基准使用脚本模型，是行为回归，不能当成真实模型成功率。
- 实际 Android/WebView 可能不报告状态，或者接受无障碍点击但没有生效。工具会提供状态与画面反馈；模型需要换定位方式、使用坐标后备或询问用户。画面变化也不等于语义目标已经完成。
- 当前没有单独集成离线 OCR。读图依靠所选模型，长文本可通过节点全文工具读取，小字可局部放大；安全窗口可能拒绝截图。
- 自动截图编号来自可读取的无障碍节点；纯画布中的按钮仍需模型从图像定位。局部截图的网格仍使用原屏幕坐标。
- 普通任务和答题任务仍有硬步数上限，分别为运行配置和 90 步；保存检查点后可由用户继续。
- 恢复的是结构化摘要和动作轨迹，不是完整模型内部上下文。进程硬杀前的最后一次异步偏好写入仍可能来不及落盘。
- 操作经验是小规模、按应用保存的路线参考；不是自动训练，也不保证适应应用改版。当前可通过清除应用数据删除本地记录。
- 微信真实账号、DeepSeek 真人登录闭环、不同厂商系统弹窗和真实长卷未在本轮全部覆盖。微信路线已去掉默认点第一项的假设，并标注未验证版本。
- 联网搜索仍使用 Bing RSS / DuckDuckGo HTML，服务或页面变更可能导致失败；文件工具仍限授权目录的文本文件。
- 电脑连接默认关闭。当前使用局域网 HTTP 与配对码，无 TLS；只应在可信网络使用。不要把 8765 端口暴露到公网。
- 安装包仍为 debug 签名；本机交付延续旧版证书，可以覆盖升级。正式分发应自行配置发布签名。
