# dsh Android

[![维护者：zhehong268](https://img.shields.io/badge/Maintainer-zhehong268-181717?logo=github)](https://github.com/zhehong268)
[![开源协议：AGPL-3.0](https://img.shields.io/badge/License-AGPL--3.0-blue)](LICENSE)

在 Android 上聊天答疑，或让模型读屏、点击和输入。支持登录 DeepSeek 账号，也可以自行配置模型服务。
手机可以独立运行任务；连接电脑后，也能通过 MCP 逐步操作。

由 [zhehong268](https://github.com/zhehong268) 维护，基于 [PocketAgent 0.2.0](https://github.com/ManojDevarajulu/PocketAgent) 修改。
当前版本：0.12.0，包名 `dev.pocketagent`。

[下载 APK](dist/dsh-phone-agent.apk) · [安装说明](dist/README.md) · [电脑连接](docs/MCP-DIRECT.md) · [测试记录](docs/VALIDATION-0.12.0.md)

## 安装

需要 Android 11 或更新版本。

1. 安装 APK，在设置里登录 DeepSeek 账号，或填写自己的模型配置。
2. 首页点“聊天答疑”即可提问，不需要无障碍。需要手机操作时再开启 dsh 无障碍服务，麦克风和通知权限按需开启。
3. 在应用内输入任务。也可以把“问 dsh”加到快捷设置磁贴，从其他应用发起任务。

读取文件前，在设置里授权一个文件夹。授权目录只读，后续读取不再逐次确认。
任务运行时，侧边面板显示目标、下一步、“对话”和“停止”。打开“对话”可补充当前任务，收起后继续执行。任务结束时面板和对话都关闭，结果弹窗随应用外观切换。
任务失败时，弹窗只提供“继续任务”。手机与电脑入口都锁定在该任务，重开应用也保留锁定。继续时恢复原目标、应用和已保存的步骤，先核对操作状态。任务完成或在运行时主动停止后，才可开始新任务。

## 功能

- 独立聊天答疑，支持连续追问、复制回答、停止、失败重试和清空记录。使用设置中的模型，不自动改用手机操作模型；聊天不读取屏幕，也不执行手机工具。
- 聊天可见记录保存在本机，重启后恢复；失败或停止后可重试，也可修改问题再发。聊天与手机任务分别保存记录，任务失败仍从“继续任务”恢复。
- 观察默认附截图。只需核对文字和控件状态时，`read_screen` 可传 `include_image=false`。画面看不清时可以放大局部或读取节点全文。
- 页面稳定等待与空控件树重读共用 50 毫秒预算，连续 25 毫秒无事件时开始读取。联系人的中间步骤复用刚读到的结果。
- 花字体优先读取运行控件中的原始 Unicode、类名、资源 ID 和边界。必要时扩大控件树读取范围，也能加载系统默认字体与当前应用公开字体资源生成字形参照。
- 观察附带系统字体缩放、字重、壁纸主色和可见背景采样，帮助判断花纹与文字。字体参照图片不能作为屏幕坐标使用。
- `open_contact` 从通讯录、搜索和资料页进入会话；同名先返回备注。`find_chat_input` 和 `fill_chat` 综合位置、资源 ID、输入能力与发送按钮寻找正文框，填写前核对会话标题，支持从语音切回文字。
- `fill_chat(open_if_needed=true)` 合并查找完整联系人、核对会话和填写草稿。搜索结果尚未出现时短暂复查，重名时返回候选，发送仍单独确认。
- 按文字、控件类型、输入状态、资源 ID、节点或截图编号定位。文字较多时优先保留输入框和按钮；重名返回候选，旧页面的编号不能继续使用。
- 输入、清空和追加优先通过剪贴板整段粘贴，不在用户键盘上逐字点击。仅在粘贴接口不可用时改用控件写入或无障碍输入连接；派发后只核对实际草稿，结果不明不再次写入。另支持上下滚动查找、长按、双击和拖动，发送按钮禁止双击。
- 一次规划可连续执行 1 到 4 步安全动作，每步重新读取页面并按语义找控件。重名、目标缺失、状态未知或需要确认时停止；发送单独处理。最后一步填写或发送通过本地核验后，可直接结束任务。
- 搜索网页、读取网页正文，在已授权目录读取文本文件。
- 连续失败或反复来回切页时复核路线。有可用的独立复核模型时，每个任务自动复核最多两次；相关用量计入任务。
- 保存任务进度，按当前任务检索相关的已验证路线。普通导航和输入自动执行；发送、删除、交卷等操作保留确认。微信发送不再先提问再弹一次卡。新增正文气泡且输入框清空后才通过消息核验；结果不明时阻止重复发送，中断后仍保留这个状态。

手机操作默认使用可看图的 `deepseek-flash`，难题可按需交给 `deepseek-v4-pro` 复核。
配置 Pro 时，操作部分仍会改用 Flash。其他服务商使用用户保存的配置。
DeepSeek 操作明确开启思考并使用 `high`，独立复核使用 `max`。保留多轮工具调用的原始推理块；输出截断时扩大预算重试一次，截断的工具不执行。只保留最近两张截图，长上下文压缩旧界面，不改动带签名的助手内容。

## 构建

需要 JDK 17 和 Android SDK 36。工程路径请使用 ASCII 字符；当前 AGP 配置不接受中文路径。
设置好 `JAVA_HOME`、`ANDROID_HOME` 后，在工程目录运行：

```powershell
.\gradlew.bat :app:testDebugUnitTest --rerun-tasks
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。Linux 和 macOS 使用 `./gradlew`。
首次构建需要下载依赖，已有完整缓存时可以加 `--offline`。

本地构建、Android 16 设备回归和真实模型联调范围见[测试记录](docs/VALIDATION-0.10.0.md)。

## 已知问题

- 锁屏时不显示任务结果弹窗，解锁后显示。无障碍服务被系统终止时，弹窗不再保留；已保存的任务记录仍可在应用内查看。

- 聊天当前支持文字，回答整段返回，没有附件、流式输出或联网搜索。最多保存最近 40 条可见消息，长会话按模型预算裁剪旧上下文；进程重建后按可见记录恢复，不保存私密推理。聊天与手机任务同时使用前台界面时互斥。
- 部分 WebView 不上报勾选状态，此时显示 `checked=unknown`。节点点击改用一次实际触摸，并核对结果；不能靠系统接受事件就判定成功。
- 截图编号来自无障碍节点。纯画布上的按钮仍靠模型看图定位；没有单独集成离线 OCR，安全窗口可能禁止截图。逐步附图会增加模型用量和等待时间；不支持图片的模型只能使用节点。
- Android 16 使用独立 AOSP 模拟器测试；微信 8.0.79 真机、真人账号登录、不同厂商系统和长任务还没有完整测过。真实模型联调用本地原生聊天应用，不能替代微信验证。消息核验针对能读到正文与输入框的文字聊天；图片、语音、自绘界面和对方是否收到，不能由这套规则确认。
- `read_ui_source` 读取的是应用上报的运行控件结构，不是反编译源码。纯画布可能没有原始文字；系统字体列表和 APK 公开字体不一定等于当前应用实际使用的字体。私有下载字体、微信数据库和聊天壁纸原文件不能直接读取，壁纸只取公开主色与屏幕可见背景。
- 粘贴成功且剪贴板仍属于本次输入时才恢复原内容，期间用户复制的新内容会保留。粘贴已派发但未核验时保留待粘贴文字，避免延迟粘贴读到旧剪贴板；这时需要核对草稿。
- 进度保存的是摘要和动作记录。进程被直接杀掉时，最后一次写入可能丢失；恢复后要先查清发送、提交等操作是否已完成。
- 新版会保存待核验发送的正文摘要值与原会话标识，恢复时继续核验，不保存正文或截图。旧版没有该依据的记录仍需人工核对。超过最近 12 个未完成任务时，旧记录保留原目标和失败摘要，已完成步骤可能不完整。
- 自动复核依赖当前服务商提供可用的第二模型，会增加等待与用量；没有复核模型时仍返回失败和循环提示。
- 普通手机任务最多 120 次模型决策及 120 次手机动作，答题任务各 360 次。手机端没有 40 秒总限时，单轮模型请求的超时是 4 分钟，电脑提交任务的请求最多等待 30 分钟。电脑直接控制仍有自己的空闲等待限制。
- QQ 和 TIM 会展开控件树并检查本人消息的正文、会话和输入框。完全自绘或被系统隐藏的气泡需要人工核对。尚未验证实际 QQ 账号和不同厂商后台管理。
- 无障碍授权和服务连接分别显示。已授权但服务未连接时等待 Android 重连。若系统实际撤销授权，仍需在系统设置里开启。
- 真实模型耗时受网络、截图和思考长度影响；连续操作与本地收尾需要模型选用相应工具参数。复杂任务的额外复核会增加请求，不能保证固定响应速度。局域网 HTTP 模型连接还受 Android 明文网络策略限制，优先使用 HTTPS。
- 50 毫秒覆盖本地读屏前的稳定等待与空树重试。Android 读取控件、截图限频、图片编码、搜索结果核验和模型请求各自计时。
- 文件工具只处理授权目录内的文本，不能读微信私有数据库，也不创建或改写答题卡。用 `list_files` 的 `/` 查看授权目录。搜索依赖 Bing RSS 和 DuckDuckGo HTML，服务变动可能导致失败。
- 电脑连接使用局域网 HTTP 和配对码，没有 TLS。只在可信网络使用，不要开放到公网。
- 仓库 APK 使用 debug 签名，并沿用旧版证书。自行构建的包可能无法覆盖安装；正式发布需要配置自己的签名。
