## 字体与壁纸边界

`read_ui_source` 读取应用上报的运行控件原文，不是反编译或获取微信私有源码。花体只改变显示时，原始 Unicode 不受影响；纯画布没有文字节点时仍需要截图识别。
`font_reference` 实际加载系统默认字体及可访问的当前 APK 字体资源，不能保证获得应用下载到私有目录中的字体。
壁纸使用公开主色与截图中的可见背景采样，不读取微信私有背景原文件，也未申请全盘文件权限。
Android 对原始壁纸读取的限制见 [WallpaperManager](https://developer.android.com/reference/android/app/WallpaperManager)，运行文字能力见 [AccessibilityNodeInfo](https://developer.android.com/reference/android/view/accessibility/AccessibilityNodeInfo)。

粘贴已核验且剪贴板仍属于本次输入时恢复旧内容；用户中途复制的新内容不会被覆盖。派发后未核验时保留待粘贴文字，防止延迟粘贴读到旧剪贴板，返回失败并要求核对草稿。
