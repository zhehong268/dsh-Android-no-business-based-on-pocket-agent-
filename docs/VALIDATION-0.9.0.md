## 聊天与任务

聊天使用设置中的模型，独立于手机任务控制器，不要求无障碍，不读取屏幕、文件或通知，不执行手机工具。
当前聊天页占用前台时不会启动手机控制；已有手机任务运行时先完成或停止任务再进入聊天。
聊天问题与会话上下文会发给用户配置的模型服务，可见记录仅保存在应用私有目录，可清空。最多保留最近 40 条消息和 128K 字符；旧上下文按模型预算裁剪。
同一运行会话保留服务商原生多轮内容；进程重建后按可见消息恢复上下文，不持久保存私密推理。退出页面会停止当前请求，未完成问题可重试。
聊天只提供文字，回复整段返回，不支持附件或联网搜索。

手机任务的恢复进度和聊天记录使用不同存储。0.8.0 的“继续任务”、发送核验、300 毫秒稳定等待及可拖动运行面板保留，具体耗时边界见[上一版记录](VALIDATION-0.8.0.md)。
