## 构建和单测

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:compileReleaseKotlin :app:lintDebug --rerun-tasks --offline --console=plain
```

946 项单测，0 失败、1 跳过。跳过的是真实服务商调用测试。Debug APK、Release 分支编译通过，Lint 0 错误、112 条警告。

新增用例覆盖聊天导航与输入免确认、单次发送确认、拒绝后不发送、密集页面附图、旧写入工具强制拒绝、目录授权撤销、文件内容隔离、运行摘要转发，以及带有付款子标签的按钮。
脚本模型用于核对执行器和确认规则，不能用于计算真实模型的任务成功率。

## 设备检查

`tools/device-smoke.mjs` 的 29 项检查通过，使用实际 AccessibilityService、手势、输入、截图和 HTTP MCP。

- WebView 单次触摸生效；勾选状态不可靠时返回未知并附图。
- 中文输入、精确姓名、重名拒绝、旧截图编号失效和区域放大通过。
- 本地聊天页能打开联系人、输入中文，经一次确认只发出一条消息，随后看见正文和已发送标记。
- 运行面板可见；实际点击面板停止按钮后，任务停止、面板移除，后续操作被拒绝。
- 本地模型夹具返回检查点后，面板显示目标与下一步；正常完成和模型错误后均移除。
- 人工查看运行、进度和空闲截图，文字及停止按钮完整，空闲时没有残留面板。模型收到的截图隐藏运行面板。

聊天页和模型服务都是本地测试夹具，没有联系真实用户。脚本临时替换模拟器的模型配置，原配置只保存在内存，结束后恢复，并清除临时配对码及端口映射。
