# 权限与确认

## 数据范围

任务会把当前应用的文字、控件状态和截图发送给用户配置的模型服务。图片模型每次观察都附图；密码框不读取，截图会遮挡已识别的密码区域。无法识别的敏感内容仍可能出现在画面里。
通知需单独开启权限；验证码会尝试遮盖，银行、支付等内容通过规则过滤。词表可能漏检。

文件只通过系统目录选择器授权，不能读取目录以外的路径或微信私有数据库。文件工具只读；`write_file` 和 `quiz_record` 不提供给模型，即使模型自行调用也会拒绝。Android 文件实现也不执行写入，并尝试释放旧授权里的持久写权限。
应用自己的设置、任务记录、恢复进度和路线摘要仍保存在应用私有存储。

## 执行规则

普通打开页面、点击输入框、输入和滚动不逐次询问。发送、拨号、付款、删除、安装、交卷和拖动等操作按风险确认；银行、支付、密码管理器及系统权限界面受拦截名单限制。
微信收件人不清楚或重名时仍需澄清。最终发送使用系统确认卡，避免提前提问后再次确认。

坐标点击会匹配当前位置的节点。普通无标签导航可执行；出现付款、删除等敏感上下文时，无标签位置仍需确认。通用“确认/确定”按钮结合页面内容判断，不再单凭这个词拦截普通导航。`irreversible=true` 可以提高风险，不能降低已有风险。

执行前核对应用、节点标签和边界。无标签坐标额外核对窗口、资源 ID 与控件类型。过期编号、密码框、dsh 自身窗口及不匹配的旧节点会被拒绝。节点点击只发一次实际触摸，不自动追加另一种点击；发送或提交结果不明时先查结果。文字消息需要新正文气泡与输入框清空共同核验，不能用草稿、旧气泡或页面变化证明成功；中断恢复保留未确认状态，模糊回答不授权重发。发送按钮禁止双击，不可用控件不弹确认。

屏幕、通知、文件和历史摘要作为不可信数据传入模型。独立复核建议同样作为资料处理，不能直接执行或绕过风险检查。数据标签不能保证模型完全免受提示注入影响，确认卡和代码中的执行限制仍是必要约束。

## 运行与停止

侧边面板仅在运行或等待用户时存在，展示简短目标、下一步和动作，不展示服务商的原始推理内容。读屏、截图和执行手势期间临时隐藏，避免挡住操作目标。
停止按钮取消运行、模型请求及确认等待。任务结束、停止、服务关闭或模型报错后移除面板；结果可在应用任务记录里查看。
普通任务默认 40 步，答题最多 90 步，电脑直接控制最多 60 步。

## 电脑连接

默认关闭。开启后使用局域网 HTTP 和配对码；每次新电脑任务或控制会话先在手机批准，后续普通操作沿用该会话。
目前没有 TLS，只在可信网络使用，不要开放到公网。停止控制、关闭连接或空闲超时会结束电脑操作。

## 保存的内容

账号凭据通过 Android Keystore 加密保存，不写进仓库。应用禁用系统备份，不保存截图和完整屏幕转储。
任务历史、未完成任务摘要和已验证路线可能包含用户任务或控件标签；它们保存在应用私有存储，不能视为完全匿名的数据。
