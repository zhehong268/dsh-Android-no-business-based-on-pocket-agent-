## 设备实测

使用单独启动的 `Medium_Phone_API_37.0` / `emulator-5556`，Android API 37、1080×2400。
没有使用真实联系人、真实发送或真实交卷；浏览器页面由本地测试服务提供，通过 adb reverse 连接。
电脑操作经过实际 MCP HTTP 请求、手机确认卡片、AgentLoop、安全门和 AccessibilityService。

- 通过：电脑控制需要手机批准后返回屏幕。
- 通过：原生点击经过安全执行链。
- 通过：不可靠状态明确标为未知并附图。
- 通过：坐标后备触摸实际完成勾选。
- 通过：中文输入通过手机工具写入。
- 通过：重名联系人返回多个候选。
- 通过：重名点击被拒绝。
- 通过：精确姓名优先于相似姓名。
- 通过：MCP 返回原生图片内容。
- 通过：刷新后旧截图编号失效。
- 通过：局部放大截图保留原屏幕坐标。
- 通过：画布页面自动附图。
- 通过：画布操作有可见反馈或风险确认。
- 通过：电脑控制可停止。
- 通过：停止后不能继续读屏。

本轮设备测试确认了两个区别：

- WebView 可能把复选框报成“不可勾选”，也可能接受无障碍点击但没有执行。不能据此直接报告任务成功。
- 不可靠状态现在明确显示 checked=unknown 并附图，必要时用坐标后备；测试页实际记录到了勾选、中文输入、精确选择和画布点击事件。

截图已人工查看，局部网格使用原屏幕坐标，画布内的三个按钮可以看见；截屏前等待字幕隐藏生效，图中不再夹带 dsh 自身字幕。
自动编号来自无障碍节点，纯画布按钮仍须模型看图定位。

测试初始化中处理了干净浏览器首启、模拟器外网不可用、服务启动等待和空 SharedPreferences 格式。
重复重连还修正了监听 socket 的 SO_REUSEADDR 设置时机。初始化失败不计为任务通过，最终结果以 15/15 记录为准。
临时配对码、端口转发和电脑连接设置已清理；原先运行的另一个模拟器未参与最终回归。

## 工作区环境前后对比

按照既有要求，修改前后都运行 env-selftest.ps1，并在最终运行 -Full。

| 档位与阶段 | PASS | WARN | FAIL | 说明 |
| --- | ---: | ---: | ---: | --- |
| 修改前，受限档 | 17 | 4 | 9 | WMI 被沙箱拒绝，进程检查跳过 |
| 修改前，完整权限 | 18 | 3 | 11 | 原桌面 DSH 安装与宿主缺失 |
| 修改后，完整权限，普通自检 | 18 | 3 | 11 | 与同档位基线相同，无新增失败 |
| 修改后，完整权限，-Full | 19 | 3 | 12 | 多出插件 verify 与 preflight 两项检查 |

原有 11 项失败：dsh-tauri 数据目录缺失、三份日志缺失、活动 profile 为空、桌面壳未运行、宿主未运行、PID 文件无效，和三项本地依赖文件缺失。
原有 3 项警告：插件错误记录不存在、桌面下拉补丁路径不存在、7877 代理未监听。

- -Full 中 **verify.mjs 97 项全部通过**，包含一次真实余额请求。
- preflight.mjs 检查发现 **28 个依赖/bundle 缺失**；与已经不存在的桌面 tauri 安装对应，未通过伪造 profile、空模块或降低断言掩盖。
- 插件测试使用独立的 DSH_TOKEN_BALANCE_LEDGER 临时路径，没有修改用户真实台账。
- 没有启动、重启或杀死桌面 DSH 壳/宿主，也没有拿关窗脚本作测试。

因此，安卓优化检查通过，但不能把整台机器的桌面 DSH 环境宣称为全绿。
