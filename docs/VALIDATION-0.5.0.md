## 新增回归

相对 0.4.0 新增 38 项单测，覆盖：

- 长文本页面的输入框和按钮保留；无标签输入框查询；全角、空白和重名匹配。
- 坐标目标换窗口、换资源 ID 或移动后拒绝；不可用发送控件不弹卡也不执行。
- 新正文气泡与空输入框共同核验；旧气泡、草稿、隐藏键盘、新失败标记不冒充成功。
- 结果不明时不重发，双击发送拒绝；未派发的点击与可能生效的中断手势分别处理。
- 中断恢复仍保留发送未确认状态；模糊回答不解除限制，明确“未发送”不能当成完成。
- 键盘提交采用消息核验；循环路线识别；独立复核两次上限、用量、取消及非法工具拒绝。
- 历史路线按任务相关性筛选。

## 设备检查

`tools/device-smoke.mjs` 的 35 项检查通过，使用实际无障碍服务、手势、输入、截图与 MCP。
除原有定位、重名、过期编号、中文输入、面板停止及结束清理外，本轮检查了：

- 按可输入状态和资源 ID 找到正文框。
- 正常发送后出现新气泡，输入框实际为空，提示词不会被当作草稿。
- 点击发送后只变为“处理中”的页面保持未确认，不把画面变化当成功。
- 草稿文字不能解除未确认状态，再次发送被拒绝，页面只收到一次触摸。

聊天页和模型服务均为本地夹具，没有联系真实用户。脚本临时替换模拟器配置并在结束后恢复；结果中不保存原配置和令牌。
脚本模型检查规则及执行器，不能用于计算真实模型成功率。微信真人账号和真机流程仍未完成验证。

## 限制
